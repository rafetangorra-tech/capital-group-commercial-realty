# Capital Group Commercial Realty

A commercial real-estate website for Capital Group Commercial Realty — the
**cinematic presentation** of a luxury-developer site paired with the
**listings functionality** of a commercial marketplace.

- **Presentation reference:** waldorftowers.nyc (cinematic, editorial, minimal)
- **Functionality reference:** Crexi listing detail pages (gallery, details grid,
  investment highlights, valuation calculator, broker contact, similar properties)

Built with **Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 ·
Motion**.

---

## Getting started

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build (also type-checks every route)
npm start          # serve the production build
```

Node 18.18+ (built and tested on Node 25).

## What's included

| Route | Purpose |
| --- | --- |
| `/` | Cinematic home — animated hero, firm statement, featured portfolio, services, approach |
| `/listings` | Filterable portfolio (search, type/status filters, sort, **card & table** views) |
| `/listings/[slug]` | Full listing detail — gallery + lightbox, details grid, description, highlights, **valuation calculator**, location map, broker card + inquiry form, similar properties |

| `/about` | Firm story, principles, market |
| `/team` | Advisor profiles |
| `/contact` | Office info, map, inquiry form |
| `/api/inquiry` | Form submission endpoint (see **Going live** below) |

## Customizing content (no code required for most of it)

Everything the client-facing site says lives in two data files:

- **`src/data/site.ts`** — company name, phone, address, email, broker of record,
  navigation, services, team members, homepage stats, and the rotating hero words.
- **`src/data/listings.ts`** — the property portfolio. Each listing is one object
  (`Listing` type is documented inline). Add, edit, or remove properties here;
  the directory, detail pages, filters, sitemap, and "similar properties" all
  update automatically.

> The **1844 Lansdowne Avenue** listing mirrors Capital Group's real public
> record. The other listings use real addresses with **illustrative sample
> economics** — replace the numbers before publishing.

### Swapping in real photography

The site ships with **AI-generated placeholder photography** (in `public/images/`,
generated with Higgsfield) so it looks finished out of the box — a cinematic home
hero, page heroes, and 3 photos per listing. These are stand-ins to be replaced
with real photography of the actual properties. If a listing has no `images`, an
art-directed SVG "plate" renders as a final fallback. To use real photos:

1. Drop images in `public/images/` (e.g. `public/images/1844-lansdowne/01.jpg`).
2. On the listing, add an `images` array:
   ```ts
   images: ["/images/1844-lansdowne/01.jpg", "/images/1844-lansdowne/02.jpg"],
   ```
   The gallery, cards, and hero use real photos whenever `images` is present and
   fall back to the generated plates otherwise. No component changes needed.

### Brand system

Colors, fonts, and the signature type treatments are defined once in
**`src/app/globals.css`** (`:root` tokens + `@theme`). Change the palette there:

- `--ink` deep navy · `--gold` brass accent · `--paper` bone ground
- Display serif = Cormorant Garamond, UI sans = Inter (swap in
  `src/app/layout.tsx` via `next/font`).

The logo is code-drawn in **`src/components/logo.tsx`** (a typographic wordmark +
skyline emblem) — easy to restyle, or replace with a supplied SVG.

## Going live: wiring the inquiry form

Submissions currently validate and log server-side in
**`src/app/api/inquiry/route.ts`**. To actually deliver them, add an email or CRM
call where indicated (one function call). Example with [Resend](https://resend.com):

```ts
import { Resend } from "resend";
const resend = new Resend(process.env.RESEND_API_KEY);
await resend.emails.send({
  from: "site@capitalgroupcr.com",
  to: "info@capitalgroupcr.com",
  subject: `New inquiry — ${inquiry.type}`,
  text: JSON.stringify(inquiry, null, 2),
});
```

## Deployment

Optimized for **Vercel**: push to a Git repo and import. `npm run build` also
works for any Node host. The build prerenders every page (listings are SSG) and
serves the inquiry route on demand.
